University Registration System:
A simple web based university registration system built using PHP and MySQL.

About The Project:
University Registration System is a website designed to help students register their personal information and access their student dashboard.
This project was created as a personal portfolio project to practice web development and database integration.

Features:

1.Student Registration Form
2.Student Dashboard
3.View Student Information
4.Edit Student Profile
5.MySQL Database Integration
6.Form Validation

Technologies Used: 

1.PHP
2.MySQL
3.HTML
4.CSS
5.JavaScript
6.XAMPP
7.Visual Studio Code

How to Run:

-Install XAMPP.
-Start Apache and MySQL.
-Create the database named university_registration.
-Import database.sql into phpMyAdmin.
-Configure your database connection.
-Move the project folder into htdocs.
-Open your browser and visit:

http://localhost/02-University-Registration/
